DVDI Scanner PWA V1
Binance Spot: BTCUSDT, KAITOUSDT
Timeframe: completed 4H candles
DVDI: sampling 255, smoothing 1
BUY: DVDI falling -> rising
SELL: DVDI rising -> falling

INSTALLATION
These files must be hosted on an HTTPS website before Android can install the PWA. Upload the contents of this folder to a static web host, open the resulting HTTPS link in Chrome, then choose Install app / Add to Home screen.

V1 is a scanner only. It does not execute trades and does not provide background push alerts while fully closed; that requires a hosted backend/push service.
